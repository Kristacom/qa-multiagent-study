## Описание
Навык предназначен для глубокого анализа архитектурных спецификаций и аналитических документов Confluence, выявления функциональных требований (FR), проверки их полноты и вычисления статуса **Quality Gate**.

---

## 1. Входные данные (Inputs)
- Текст или файл проектной спецификации Confluence (`requirements/*.md`, `.txt` или REST API выгрузка / MCP `atlassian:get_page`).
- Метаданные документа (ID, автор, версия, дата).
- Регламент маскирования чувствительной информации [`PII.md`](file:///C:/Users/Kosmos/qa-multiagent-study/PII.md) и утилита [`pii_sanitizer.py`](file:///C:/Users/Kosmos/qa-multiagent-study/pii_sanitizer.py).

---

## 2. Алгоритм выполнения (Procedure)
1. **Санитизация PII и нормализация текста:**
   - Применить правила фильтрации по `PII.md`: маскировать персональные email (`[EMAIL_REDACTED]`), телефоны (`[PHONE_REDACTED]`), ФИО (`[NAME_REDACTED]`), документы (`[DOC_REDACTED]`) и токены (`[SECRET_REDACTED]`).
   - Сохранить синтетические тестовые фикстуры (например, `user@example.com`).
   - Очистить входящий документ от служебной разметки.
   - Выделить ключевые логические блоки: эндпоинты, форматы запросов/ответов, коды ошибок.
2. **Экстракция требований:**
   - Сформировать перечень функциональных требований (`FR-01`, `FR-02`...) с заголовком и описанием.
   - Сформировать перечень нефункциональных требований (NFR): задержки (Latency), безопасность (Security), аудит (Audit).
   - Выделить бизнес-правила (Business Rules) и системные ограничения (Constraints).
3. **Аудит качества требований (Review & Ambiguities):**
   - Найти «белые пятна» (не описано поведение при таймаутах, сбоях БД, повторных вызовах).
   - Зафиксировать неоднозначные формулировки («быстро», «достаточно», «и т.д.»).
   - Выявить противоречия между разделами спецификации.
4. **Расчет Quality Gate:**
   - Если найдены неустранимые противоречия в бизнес-логике или отсутствие обязательных параметров безопасности → `passed: false` (Блокер).
   - Если требования непротиворечивы и пригодны для проектирования тестов → `passed: true`.
   - Рассчитать метрику качества (Quality Score от 0 до 100).
5. **Сохранение артефакта:**
   - Сохранить результат в файл `artifacts/ReviewReport.json` согласно контракту из `AGENTS.md`.
